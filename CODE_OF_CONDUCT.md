# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
(v2.1). In short: be respectful and assume good faith; harassment, discrimination and
personal attacks are not tolerated, in this repository or any other project space.

To report unacceptable behaviour, open a private report via
[Security → Report a vulnerability](https://github.com/sebastianstupak/gamepad-grimoire/security/advisories/new)
— the project's private channel to the maintainer. Reports are handled confidentially.
